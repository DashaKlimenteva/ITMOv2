# Нагрузочные тесты (улучшенная версия)

## Цели

- Уточнить и закрепить проверяемые сценарии нагрузки для POST `/api/reviews` на основе подтверждённых источников.
- Связать результаты с метрикой из `problem.md → Метрики`: доля 5xx на POST /api/reviews < 1%.

## Окружение и инструменты

- Генератор HTTP POST запросов (k6 или Python `requests`).
- Мок внешнего LLM с управляемой задержкой ответа.
- Логирование только `request_id`, длительности и статуса без содержимого `diff` и ответов модели (`CASE.md → OBS-1`).

## Тест-кейсы

| ID | Назначение | Предусловия | Действие | Ожидаемый результат | Evidence |
|---|---|---|---|---|---|
| L1 | Большое тело `diff` | Порог длины `diff` = 20000 символов | Отправить POST `/api/reviews` с `diff` ≈ 22000 символов (на ~10% больше порога) | HTTP 413; без 5xx; логи без содержимого | `CASE.md → API-1`; `TRAINING_PR.diff → app/api.py:35-38` |
| L3 | Таймаут LLM | Таймаут внешнего LLM = 10 секунд; доступен мок LLM | Смоделировать задержку ответа LLM > 10 секунд | Контролируемый ответ без 5xx; логи без содержимого | `CASE.md → REL-1, OBS-1`; `TRAINING_PR.diff → app/review_service.py:19-22` |

## Критерии провала

- L1: при `diff` > 20000 символов не возвращается 413; возникает 5xx; логи содержат `diff` или ответ модели (нарушение `OBS-1`).
- L3: при задержке LLM > 10 секунд возвращается 5xx вместо контролируемого ответа; логи содержат `diff` или ответ модели (нарушение `OBS-1`).

## Обоснование

- Порог 20000 символов и требование 413 подтверждены `CASE.md → API-1`.
- Таймаут 10 секунд и контролируемая ошибка — `CASE.md → REL-1`.
- Требования к логированию — `CASE.md → OBS-1`.
- Эндпоинт и вызов LLM подтверждены `TRAINING_PR.diff → app/api.py:35-38; app/review_service.py:19-22`.
- Кейс L2 (параллельные запросы) не включён: «Недостаточно данных» в исходном tests_load.md и отсутствие подтверждённых порогов/правил в источниках.

## Как использовали AI

- Использовали для выбора альтернатив и структурирования подтверждённых кейсов по источникам `CASE.md`, `problem.md → Метрики`, `TRAINING_PR.diff`. Исключали все не подтверждённые правилами сценарии.
