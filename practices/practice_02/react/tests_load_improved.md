# Нагрузочные тесты (улучшенная версия)

## Источники и пороги

- Порог длины diff: 20000 символов; запросы длиннее отклоняются 413. Источник: CASE.md → API-1.
- Таймаут внешнего LLM-вызова: 10 секунд; ошибка конвертируется в контролируемый ответ. Источник: CASE.md → REL-1.
- Метрика качества: доля 5xx на POST /api/reviews < 1%. Источник: problem.md → таблица метрик.

Переносим только кейсы, подтверждённые правилом или строкой диффа. L2 (параллельные запросы) не переносим: нет прямого подтверждения правилом/диффом.

## Инструменты и подход

- Генератор HTTP POST к `/api/reviews`.
- Мок внешнего LLM с управляемой задержкой ответа (для проверки таймаута).
- Проверка логов на соответствие OBS-1: без логирования содержимого diff/ответов, только request_id, длительность, статус.

## Критерии провала

- L1: тело > 20000 символов не приводит к 413; возвращается 5xx; логируются запрещённые данные (нарушение OBS-1).
- L3: при задержке LLM > 10 секунд нет контролируемого ответа; возвращается 5xx; логируются запрещённые данные.
