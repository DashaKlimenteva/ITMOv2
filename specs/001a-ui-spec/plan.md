# Plan: 001a UI Spec — CLI Markdown Report

## Цель

CLI-генератор отчёта в Markdown по общему контракту из `specs/contract.md`.

## Файлы

- Скрипт: `tools/new_lab_report.py`
- Шаблон: `templates/lab_report.md`

## Контракт (коды и поведение)

- `--lab < 1` → `exit 2` (ошибка аргументов)
- `--date` не в формате `YYYY-MM-DD` → `exit 2`
- Существующий целевой файл → `exit 1` (без перезаписи)
- Нет шаблона → `exit 1` (файл не создаётся)
- Успех → `exit 0` и печать абсолютного пути к созданному файлу в stdout

Дополнительно:
- Имя по умолчанию: `reports/labNN.md` (NN — zero‑pad 1–9), если `--out` не задан; требует валидного `--lab`.
- Плейсхолдеры: `{LAB}`, `{FIO}`, `{GROUP}`, `{DATE}`; если значение не передано — плейсхолдер сохраняется, кроме `{DATE}` (подставляется текущая ISO‑дата).

## Стек

Python 3.11+, только стандартная библиотека: `argparse`, `pathlib`, `datetime`.

## Не-цели

- Генерация PDF/DOCX
- Переключатель языков интерфейса
- Makefile-обёртка
