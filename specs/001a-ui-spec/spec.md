# Feature Specification: CLI Markdown Report Generator

**Feature Branch**: `[001-cli-markdown-report]`

**Created**: 2026-10-29

**Status**: Draft

**Input**: User description: "Фича: CLI-генератор Markdown-отчёта по лабораторной работе.

Ты — UI-команда. Опиши только то, что видит и делает пользователь:
- какие команды и флаги он вводит (--lab, --fio, --group, --date, --out);
- что выводится при успехе (путь к файлу, код 0);
- какие сообщения об ошибках видит пользователь и при каких условиях:

## User Scenarios & Testing (mandatory)

### User Story 1 - Generate report with all flags (Priority: P1)

Пользователь запускает CLI с флагами: `--lab 3 --fio "Иванов И.И." --group K3141 --date 2026-10-29 --out report.md`. Инструмент успешно создаёт Markdown-файл и сообщает путь к созданному файлу. Возвращаемый код процесса — 0.

**Why this priority**: Это основной сценарий использования — успешная генерация отчёта по корректно переданным аргументам.

**Independent Test**: Запустить команду с валидными аргументами и проверить, что файл существует, содержит Markdown-разметку, консоль показывает путь к файлу, процесс завершается с кодом 0.

**Acceptance Scenarios**:

1. Given валидные значения всех флагов, When команда выполнена, Then создаётся новый файл по `--out`, в stdout печатается абсолютный путь и процесс завершается кодом 0.
2. Given путь `--out` указывает на несуществующий файл в доступной директории, When команда выполнена, Then файл создаётся.

---

### User Story 2 - Auto output name (Priority: P2)

Пользователь не указывает `--out`. Команда выбирает разумное имя файла по умолчанию и сообщает путь к созданному файлу.

**Why this priority**: Улучшает UX в типичном случае, когда путь не указан.

**Independent Test**: Запустить без `--out`, убедиться, что файл создан в текущей директории и путь выведен в stdout, код возврата 0.

**Acceptance Scenarios**:

1. Given не указан `--out`, When команда выполнена, Then выводится путь к созданному файлу по умолчанию и код возврата 0.

---

### User Story 3 - Argument error messages (Priority: P2)

Пользователь ошибочно передаёт или опускает флаги. Команда печатает понятные сообщения об ошибках и возвращает код 2.

**Why this priority**: Ясные ошибки уменьшают время на исправление ввода.

**Independent Test**: Запуск с отсутствующим `--lab`, с нечисловым `--lab`, с `--lab 0` или `< 1` — проверить текст ошибок и код 2.

**Acceptance Scenarios**:

1. Given отсутствует `--lab`, When команда запускается, Then stderr содержит "Ошибка: флаг --lab обязателен" и процесс завершается кодом 2.
2. Given `--lab` не число, When команда запускается, Then stderr содержит "Ошибка: --lab должен быть целым числом" и код 2.
3. Given `--lab < 1`, When команда запускается, Then stderr содержит "Ошибка: --lab должен быть >= 1" и код 2.

---

### Edge Cases

- Путь `--out` указывает на уже существующий файл: команда сообщает об ошибке "Файл уже существует" и завершает работу с кодом 1.
- Нет доступного шаблона: команда сообщает об ошибке шаблона и завершает работу с кодом 1.

## Requirements (mandatory)

### Functional Requirements

- FR-001: Команда должна принимать флаги: `--lab <int>`, `--fio <string>`, `--group <string>`, `--date <YYYY-MM-DD>`, `--out <path>`.
- FR-002: При успешной генерации команда выводит абсолютный путь к созданному файлу в stdout и завершает работу с кодом 0.
- FR-003: Если файл по пути `--out` уже существует, команда прекращает работу, печатает ошибку о существующем файле в stderr и возвращает код 1.
- FR-004: Если `--lab` не передан (и не задан `--out`), команда печатает ошибку о том, что `--lab` обязателен, и возвращает код 2.
- FR-005: Если `--lab` не является числом, команда печатает ошибку о некорректном формате и возвращает код 2.
- FR-006: Если `--lab < 1`, команда печатает ошибку о допустимом диапазоне и возвращает код 2.
- FR-007: Если шаблон недоступен/не найден, команда печатает ошибку шаблона и возвращает код 1.
- FR-008: При отсутствии `--out` вывод по умолчанию создаётся по пути `reports/labNN.md` (NN — двузначный для 1–9, иначе без нуля); путь выводится в stdout. Требует валидного `--lab`.
- FR-010: Если `--date` не в формате `YYYY-MM-DD`, команда печатает ошибку о некорректном формате даты и возвращает код 2.
- FR-009: Сообщения об ошибках формулируются на русском языке и описывают причину и требуемое действие пользователя.

### States

- Успех: файл создан; в stdout напечатан абсолютный путь; код возврата 0.
- Ошибка аргументов: неверный или отсутствующий `--lab`, некорректная `--date`; сообщение об ошибке в stderr; код возврата 2; файл не создаётся.
- Ошибка файла: `--out` указывает на существующий файл или недоступный путь; сообщение об ошибке в stderr; код возврата 1; файл не создаётся.
- Ошибка шаблона: шаблон недоступен/не найден; сообщение об ошибке в stderr; код возврата 1; файл не создаётся.

### Key Entities

- Параметры запуска CLI: значения флагов, влияющие на генерацию пользовательского отчёта.
- Выходной файл отчёта: Markdown-файл, создаваемый по указанному или умолчанию пути.

## Success Criteria (mandatory)

### Measurable Outcomes

- SC-001: 95% успешных запусков с валидными аргументами завершаются менее чем за 2 секунды с кодом 0 и выводом пути к файлу.
- SC-002: 100% запусков с отсутствующим `--lab` выводят корректное сообщение об ошибке и завершаются ненулевым кодом.
- SC-003: 100% запусков с нечисловым `--lab` выводят корректное сообщение об ошибке и завершаются ненулевым кодом.
- SC-004: 100% запусков с `--lab < 1` выводят корректное сообщение об ошибке и завершаются ненулевым кодом.
- SC-005: 100% запусков с указанием существующего `--out` не перезаписывают файл, а выводят ошибку и завершаются ненулевым кодом.
- SC-006: В 100% случаев при отсутствии шаблона выводится ошибка шаблона, процесс завершается ненулевым кодом, файл не создаётся.

## Assumptions

- По умолчанию путь вывода — `reports/labNN.md` (NN — zero-pad для 1–9, иначе число без нуля), если `--out` не указан.
- Дата в `--date` ожидается в формате `YYYY-MM-DD`.
- Сообщения и интерфейс русскоязычные, как в описании.
- При ошибках аргументов возвращается код 2; при ошибках файла/шаблона — код 1; при успехе — 0.
