# Design

## File Structure

- tools/new_lab_report.py — CLI-утилита генерации отчёта (чистый Python, без внешних зависимостей).
- templates/lab_report.md — внешний редактируемый шаблон Markdown с плейсхолдерами.
- reports/ — каталог отчётов по умолчанию; создаётся при первом запуске, если отсутствует.

## CLI Arguments

- `--lab` (int): номер лабораторной. Обязателен, если не указан `--out`. Используется для имени файла по умолчанию и подстановки `{LAB}` в шаблон.
- `--fio` (str): значение для подстановки в `{FIO}`.
- `--group` (str): значение для подстановки в `{GROUP}`.
- `--date` (str): значение для подстановки в `{DATE}`; формат ожидается ISO `YYYY-MM-DD`.
- `--out` (path): явный путь назначения файла отчёта. Приоритет выше имени по умолчанию; при указании `--out` каталог и имя берутся из этого аргумента.

Поведение по умолчанию:
- При отсутствии `--out` целевой путь формируется как `reports/labNN.md`, где `NN` — номер из `--lab` с ведущим нулём для 1–9.
- При наличии `--out` используется указанный путь; `--lab` в этом случае влияет только на подстановку `{LAB}` и может быть опущен — тогда `{LAB}` остаётся плейсхолдером (см. Placeholder Rules).

## Placeholder Rules

Плейсхолдеры в шаблоне:
- `{LAB}`, `{FIO}`, `{GROUP}`, `{DATE}`.

Правило подстановки:
- Если соответствующий аргумент передан, значение подставляется.
- Если аргумент не передан, плейсхолдер остаётся в результирующем файле неизменённым. Это контракт из спецификации, позволяющий ручное заполнение.

## Existence Check and Error Policy

- Проверка наличия целевого файла выполняется до записи.
- Если файл назначения уже существует:
  - Печатается понятное сообщение об ошибке в stderr.
  - Процесс завершается с ненулевым кодом возврата (1).
  - Существующий файл не изменяется и не перезаписывается.

## Path and Date Policy

- Имя файла по умолчанию: `reports/labNN.md`.
  - Ведущий ноль для 1–9: `lab01.md … lab09.md`.
  - Для `N >= 10`: `labNN.md` без дополнительных нулей (например, `lab10.md`).
- Дата:
  - Если `--date` передан — используется значение, ожидаемый формат ISO `YYYY-MM-DD`.
  - Если `--date` не передан — используется системная дата в формате ISO `YYYY-MM-DD`.

## Cross-Platform Considerations

- Использовать `pathlib` для операций с путями и создания директорий, без ручной склейки строк.
- Не использовать внешние зависимости; только стандартная библиотека (`argparse`, `pathlib`, `datetime`).
- В рамках этой фичи не добавляется make-обёртка; запуск — через Python.

## Reports Directory Creation

- При генерации пути по умолчанию (без `--out`) и отсутствии каталога `reports/` — каталог создаётся автоматически перед записью файла отчёта.
- Для `--out` — создаются недостающие родительские каталоги указанного пути.

## Non-Goals

- Генерация PDF/DOCX.
- Автоматическое оглавление/индексация отчётов.
- Валидация содержимого разделов отчёта.
- Переключатель языков (ru/en).
- CI-интеграция и автоматическая публикация.
- Обёртка в Makefile.
