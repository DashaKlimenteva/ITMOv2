# Proposal

## Why

Работа с отчётами по лабораторным сейчас выполняется вручную, что приводит к расхождениям по структуре, названию файлов и содержанию разделов. Нужен простой и воспроизводимый способ создавать новый Markdown-отчёт по шаблону без правки кода.

## What Changes

- Добавить CLI-утилиту на Python (`tools/new_lab_report.py`), создающую новый Markdown-отчёт из внешнего шаблона `templates/lab_report.md`.
- Поведение по умолчанию: запись в `reports/labNN.md` (с ведущим нулём для 1–9) при задании `--lab N`.
- Поддержка аргументов для заполнения полей ФИО/Группа/Дата; если аргумент не передан — в отчёте остаётся плейсхолдер.
- Если файл назначения уже существует — завершение с ненулевым кодом, без изменений файла.
- Шаблон вынесен в отдельный файл; его можно менять без изменения кода.
- Язык: русский; без переключателя языков.
- Дата по умолчанию — системная (ISO `YYYY-MM-DD`), если `--date` не указан.
- Аргумент `--out` позволяет переопределить путь назначения.

## Capabilities

### New Capabilities
- `cli/lab-report-generator`: генерация Markdown-отчёта по лабораторной работе из внешнего шаблона с предсказуемыми именованием и поведением, без перезаписи существующих файлов.

### Modified Capabilities
- (нет)

## Impact

- Новые файлы: `tools/new_lab_report.py`, `templates/lab_report.md`.
- Новая директория с отчётами по умолчанию: `reports/` (создаётся при первом запуске, если отсутствует).
- Отсутствуют внешние зависимости; используется стандартная библиотека Python (argparse, pathlib, datetime).
- Поведение не затрагивает существующие файлы и отчёты; перезапись исключена контрактом.
