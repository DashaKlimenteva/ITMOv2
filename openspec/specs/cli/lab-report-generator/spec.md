# lab-report-generator Specification

## Purpose
Обеспечить воспроизводимое создание Markdown-отчётов по лабораторным работам на основе внешнего шаблона, без перезаписи существующих файлов.

## Requirements

### Requirement: Генерация отчёта по шаблону
Система SHALL создавать новый файл отчёта в формате Markdown на основе шаблона `templates/lab_report.md`.

#### Scenario: Создание отчёта по умолчанию
- **WHEN** пользователь запускает команду с `--lab N` без `--out`
- **THEN** создаётся файл `reports/labNN.md` (с ведущим нулём для 1–9)
- **THEN** содержимое формируется из шаблона с плейсхолдерами, заменёнными переданными значениями (если указаны)

#### Scenario: Создание отчёта в указанный путь
- **WHEN** пользователь запускает команду с параметром `--out <path>`
- **THEN** создаётся файл по указанному пути
- **THEN** содержимое формируется из шаблона по тем же правилам

### Requirement: Поля заголовка и разделов
Система SHALL формировать отчёт с заголовком «Лабораторная работа №N» и разделами: «Цель», «Ход работы», «Результаты», «Вывод», а также полями «ФИО», «Группа», «Дата».

#### Scenario: Подстановка переданных полей
- **WHEN** переданы аргументы `--fio`, `--group`, `--date`
- **THEN** в отчёт подставляются соответствующие значения вместо плейсхолдеров `{FIO}`, `{GROUP}`, `{DATE}`

#### Scenario: Плейсхолдеры при отсутствии аргументов
- **WHEN** какой-либо из аргументов не передан
- **THEN** соответствующий плейсхолдер остаётся неизменённым в результирующем файле

### Requirement: Поведение при существующем файле
Система SHALL не перезаписывать существующие отчёты.

#### Scenario: Файл уже существует
- **WHEN** целевой файл отчёта уже существует
- **THEN** команда завершается с ненулевым кодом возврата и информативным сообщением
- **THEN** существующий файл остаётся без изменений

### Requirement: Значение даты по умолчанию
Система SHALL использовать системную дату в формате ISO `YYYY-MM-DD`, если аргумент `--date` не указан.

#### Scenario: Дата по умолчанию
- **WHEN** не передан аргумент `--date`
- **THEN** в отчёт подставляется текущая системная дата в формате ISO `YYYY-MM-DD`

### Requirement: Кроссплатформенность и отсутствие зависимостей
Система SHALL работать на Windows и Unix-подобных ОС без внешних зависимостей.

#### Scenario: Стандартная библиотека
- **WHEN** выполняется команда генерации
- **THEN** используется только стандартная библиотека Python (например, `argparse`, `pathlib`, `datetime`)

### Requirement: Ошибки аргументов командной строки
Система SHALL завершаться с ненулевым кодом возврата и понятным сообщением, если аргумент `--lab` не передан (при отсутствии `--out`) или не является целым числом.

#### Scenario: Не передан --lab
- **WHEN** команда запущена без `--lab` и без `--out`
- **THEN** выводится понятное сообщение об ошибке
- **THEN** код возврата ненулевой
- **THEN** файл отчёта не создаётся

#### Scenario: --lab не является целым числом
- **WHEN** `--lab` передан со значением, которое не является целым числом (например, `abc`)
- **THEN** выводится понятное сообщение об ошибке
- **THEN** код возврата ненулевой
- **THEN** файл отчёта не создаётся

### Requirement: Поведение при отсутствии шаблона
Система SHALL завершаться с ненулевым кодом возврата и понятным сообщением, если файл `templates/lab_report.md` отсутствует.

#### Scenario: Нет файла шаблона
- **WHEN** файл `templates/lab_report.md` отсутствует
- **THEN** выводится понятное сообщение об ошибке
- **THEN** код возврата ненулевой
- **THEN** файл отчёта не создаётся

### Requirement: Автосоздание папки reports
Система SHALL создавать папку `reports/`, если её нет, перед записью отчёта по умолчанию.

#### Scenario: Папки reports нет
- **WHEN** папки `reports/` нет и `--out` не указан
- **THEN** папка `reports/` создаётся
- **THEN** файл отчёта создаётся
- **THEN** код возврата нулевой
